# Green Campus: โปรเจกต์ตั้งต้น (Prototype ที่รันได้จริง)

เกม 3D สำรวจวิทยาลัยสีเขียว + ภารกิจกิจกรรมจริง + AI ตรวจรูปหลักฐาน + Green Points + ร้านแลกรางวัล + Certificate (PDF พร้อม QR)

## 1. เลือกภาษา/เทคโนโลยีอะไร (และเหตุผล)

**แนะนำ: JavaScript ทั้งระบบ (Node.js ฝั่งเซิร์ฟเวอร์ + Three.js ฝั่งเกม)** เหตุผล:

| ปัจจัย | JavaScript + Three.js (โปรเจกต์นี้) | Unity (C#) |
|---|---|---|
| ติดตั้ง | แค่ Node.js, เปิดเบราว์เซอร์เล่นได้ | ต้องลง Unity (หลาย GB) เครื่องต้องแรง |
| ผู้เล่น | นักเรียนเปิดลิงก์ผ่านมือถือ ไม่ต้องโหลดแอป | ต้อง build เป็น WebGL (ไฟล์ใหญ่ โหลดช้า) หรือแอป |
| ภาษาเดียวทั้งทีม | ใช้ภาษาเดียวกับหลังบ้านและหน้าครู | ต้องเรียน C# เพิ่ม + แยกโค้ดหลังบ้านอีกภาษา |
| กราฟิกตัวละครอนิเมะ | ทำได้ (โหลดโมเดล .glb/.vrm) แต่ต้องทำเอง | **ดีกว่า** มี asset/เครื่องมือเยอะ |
| เกมใหญ่ในอนาคต | พอได้ถึงขนาดวิทยาลัยย่อม | **เหมาะกว่า** ถ้าต้องการกราฟิกสวยมาก |

**สรุป:** ถ้าโปรเจกต์ต้องเสร็จทันประกวดและทีมไม่เคยทำเกม 3D มาก่อน ใช้ชุดนี้ ถ้าทีมมีคนเก่ง Unity และมีเวลา 3 เดือนขึ้นไป ให้ทำฝั่ง Unity (C#) แล้วเรียก **API เดิมของโปรเจกต์นี้** ได้เลย เพราะระบบหลังบ้าน (ภารกิจ, AI, คะแนน, Certificate) แยกจากตัวเกมอยู่แล้ว

| ส่วน | เทคโนโลยี | ไฟล์ |
|---|---|---|
| เกม 3D + UI | HTML + JavaScript + Three.js (r128) | `client/index.html` |
| หลังบ้าน API | Node.js + Express | `server/index.js` |
| ฐานข้อมูล | SQLite (better-sqlite3) ไม่ต้องติดตั้งเซิร์ฟเวอร์ DB | `server/db.js` |
| AI ตรวจรูป | Claude API (Vision) หรือโหมดจำลอง | `server/ai.js` |
| Certificate | pdfkit + qrcode + ฟอนต์ Sarabun | `server/index.js` |
| หน้าครู | HTML ธรรมดา | `admin/index.html` |

## 2. วิธีรัน

ต้องมี Node.js 18 ขึ้นไป (https://nodejs.org)

**Windows (ง่ายสุด):** ดับเบิลคลิก `start.bat` ที่โฟลเดอร์หลัก (ติดตั้งแพ็กเกจ สร้าง `.env` และรีสตาร์ตตัวเองให้)

**หรือพิมพ์เอง:**
```
cd server
npm install
copy .env.example .env
notepad .env
npm start
```

- เกม: http://localhost:3000 · หน้าครู: http://localhost:3000/admin
- ไม่ใส่ API key = โหมดจำลอง (ไม่ได้ตรวจรูปจริง ห้ามใช้กับรางวัลจริง)
- **ขึ้นระบบใช้งานจริง อ่าน `DEPLOY.md`** (เช็กลิสต์, HTTPS, สำรองข้อมูล, ค่าใช้จ่าย AI)
- วัดความแม่นของ AI กับรูปจริง: `node tools/eval-ai.js` (ดูวิธีใน `server/samples/README.txt`)

## 4. โครงสร้างข้อมูล (ย่อ)

`users` (points, coins, exp, lifetime_points) · `missions` (type, category, points, ai_hint, certificate) · `submissions` (status, ai_confidence, image_hash) · `certificates` (serial) · `rewards` / `redemptions` · `minigame_plays` (ใช้คุมเพดานคะแนนเกมต่อวัน)

ทำไมแยก `points` กับ `lifetime_points`: แลกของแล้ว `points` ลด แต่อันดับต้องไม่ตกจากการใช้คะแนน

## 5. AI Green Checker ทำงานอย่างไร

1. นักเรียนถ่ายรูป → ฝั่งเกมย่อรูป (≤1280px) → อัปโหลด
2. เซิร์ฟเวอร์เช็ก **รูปซ้ำ** (SHA-256) ก่อนเรียก AI
3. ส่งรูป + คำอธิบายว่า "รูปที่ถูกต้องของภารกิจนี้ควรเป็นอย่างไร" (`missions.ai_hint`) ให้ Claude
4. Claude ตอบ JSON: `relevant`, `quality_ok`, `confidence`
5. ตัดสินใจ: ผ่านเมื่อ relevant + คุณภาพดี + มั่นใจ ≥ 0.8 · ส่งใหม่เมื่อไม่เกี่ยวข้อง/ไม่ชัดและมั่นใจ ≥ 0.8 · ที่เหลือ **ส่งครูตรวจ**
6. ถ้า AI ล่ม จะไม่ให้ผ่านเอง แต่ส่งครูตรวจ

ปรับ `ai_hint` ของแต่ละภารกิจให้เฉพาะเจาะจงจะแม่นขึ้นมาก

## 6. ความปลอดภัยและข้อจำกัด

ทำแล้ว: PIN เก็บแบบ hash (scrypt) · ล็อก 15 นาทีเมื่อใส่ PIN/รหัสครูผิดเกิน 8 ครั้ง · เซสชันหมดอายุ 30 วัน · จำกัดส่งหลักฐาน 10 รูป/ชม. · เพดานรูปที่ส่ง AI ต่อวัน (`AI_DAILY_LIMIT`) · เฉลยเกม/Quiz ตรวจที่เซิร์ฟเวอร์ · เกมให้คะแนนสูงสุด 8/ครั้ง 20/วัน · ติ๊กยินยอมก่อนสมัคร (บันทึกเวลา) · ลบรูปอัตโนมัติเมื่อครบ `IMAGE_KEEP_DAYS` · สำรองฐานข้อมูลรายวัน · ครูเพิกถอนคะแนนจากรูปที่ AI ผ่านผิดได้ · ป้องกัน CSV formula injection

ข้อจำกัดที่ยังมี:
- **AI พิสูจน์ไม่ได้ว่ากิจกรรมเกิดขึ้นจริง** กันรูปซ้ำได้เฉพาะไฟล์ที่เหมือนกันทุกไบต์ จึงต้องสุ่มตรวจโดยครู (แท็บ "สุ่มตรวจที่ AI ผ่าน")
- ล็อกอินด้วยรหัสนักเรียน + PIN ที่นักเรียนตั้งเอง ใครรู้ทั้งคู่เข้าแทนได้ รางวัลมูลค่าสูงควรให้รับของพร้อมบัตรนักเรียน
- SQLite บนเครื่องเดียว เหมาะระดับหลักร้อยคนพร้อมกัน ถ้าทั้งวิทยาลัยหลายพันคนควรย้ายฐานข้อมูล
- ส่งรูปให้ Claude API = ข้อมูลออกนอกเครื่อง ต้องแจ้งนักเรียน/ผู้ปกครองตาม PDPA ของวิทยาลัย
- ยังไม่มีแจ้งเตือนนักเรียนเมื่อครูอนุมัติ (ดูได้ที่ โปรไฟล์ → ประวัติการส่งหลักฐาน)

## 7. Roadmap ต่อจากนี้ (เรียงตามความคุ้ม)

1. **เปลี่ยนตัวละครเป็นโมเดลอนิเมะจริง** — สร้างด้วย VRoid Studio ส่งออก .vrm → ใช้ไลบรารี `@pixiv/three-vrm`, แอนิเมชันเดิน/วิ่งจาก Mixamo; เปลี่ยนที่ฟังก์ชัน `person()` ใน `client/index.html`
2. **เปลี่ยนกล่องเป็นโมเดลอาคาร/ต้นไม้** (ไฟล์ .glb ฟรีจาก Poly Pizza, Kenney.nl, Sketchfab ที่ใบอนุญาตอนุญาต) ด้วย `GLTFLoader`
3. **เพิ่มภารกิจ/บทเรียน**: ภารกิจเพิ่มได้ที่ `server/db.js` (seed) หรือสร้างหน้า CRUD ในหน้าครู; บทเรียนเพิ่มที่ `server/content.js`
4. **My Green Farm**: ตาราง `plots(user_id, slot, plant, planted_at)` — ต้นไม้โตตามเวลาจริงคำนวณจาก `planted_at` ฝั่งเซิร์ฟเวอร์ (ไม่ต้องมี timer ใน DB)
5. **กระเป๋า + ร้านไอเทมในเกม**: ตาราง `inventory(user_id, item, qty)` ใช้ Green Coin ซื้อ
6. **ทีม/ห้องเรียนแข่งกัน + Green Class ประจำเดือน**: query จาก `users.classroom` ที่มีอยู่แล้ว
7. **Banner/Event**: ตาราง `events(title, text, starts_at, ends_at)` + แถบข้อความบนจอ
8. **ย้ายเป็น PostgreSQL/Supabase** เมื่อมีผู้ใช้พร้อมกันเกินหลักร้อย

## 8. หากต้องการใช้ Unity (C#) แทนส่วนเกม

ฝั่งเซิร์ฟเวอร์ใช้ต่อได้ทันที เรียกผ่าน `UnityWebRequest` แล้วส่ง `Authorization: Bearer <token>`

| Endpoint | หน้าที่ |
|---|---|
| `POST /api/login` | เข้าสู่ระบบ (studentId, name, classroom, pin) |
| `GET /api/me` | โปรไฟล์ + Impact + Badge |
| `GET /api/missions` | รายการภารกิจ |
| `POST /api/submissions` | multipart: `missionId`, `image` |
| `POST /api/minigame` | `{game, score}` |
| `GET /api/rewards` · `POST /api/rewards/:id/redeem` | ร้านค้า |
| `GET /api/leaderboard` | อันดับ |
| `GET /api/certificates/:serial/pdf` | ดาวน์โหลดใบประกาศ |

## 9. โครงสร้างโฟลเดอร์

```
green-campus/
├─ client/index.html      เกม 3D + UI ทั้งหมด
├─ admin/index.html       หน้าครู: ตรวจ/สุ่มตรวจ/ส่งมอบรางวัล/ภารกิจ/นักเรียน/CSV
├─ start.bat · DEPLOY.md  เปิดเซิร์ฟเวอร์บน Windows · คู่มือขึ้นระบบจริง
└─ server/
   ├─ index.js            API ทั้งหมด
   ├─ db.js               ตาราง + ข้อมูลตั้งต้น (ภารกิจ ของรางวัล)
   ├─ ai.js               AI Green Checker (timeout, ลองซ้ำ, ปรับ AI_PASS ได้)
   ├─ env.js              โหลดไฟล์ .env
   ├─ tools/eval-ai.js    วัดความแม่นของ AI กับรูปจริง
   ├─ content.js          บทเรียน/Quiz
   ├─ fonts/              Sarabun สำหรับ PDF (ลิขสิทธิ์ OFL)
   └─ .env.example
```
